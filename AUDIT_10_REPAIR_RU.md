# Обработка причин из arbitrage_compact_audit (10).zip

Архив сформирован 20.10.2026 18:26 Екатеринбург. Рыночных исполнений A/B
нет. Записи после 17:55:48 используются отдельно от прежних версий. Число
отказов — число проверок, не количество уникальных упущенных сделок.

| Причина | Принятое решение |
|---|---|
| HTTP503 | Уже действует exponential backoff на сеть. Не создавать котировку при отказе; разрешённый резервный провайдер проходит те же проверки. Без рабочего источника вход невозможен. Старые записи request_sent=false являются ожиданием, а не новым HTTP503. |
| HTTP400 / code4008 | Добавлены безопасная категория известных сообщений, длина и SHA256 ответа. Никакого вывода причины только из числа4008. Недоступные маршруты повторяются через15с, а не занимают каждый проход. |
| HTTP403 | Отдельный circuit breaker на доступ провайдера. Сохраняются попытки primary/fallback; 0x403 после Kyber503 не объявляется ошибкой Kyber. Ключ/доступ сервиса кодом не подменяется. |
| RECOVERY_BOOK_STALE | Новый запрос и повторная проверка один раз; 1.5с не увеличивается. При повторном отказе сохраняются возраст, порог и число попыток. |
| PUBLIC_BOOK_STALE | Уже реализован новый REST запрос один раз. Порог3с сохраняется. Не заменять биржевой timestamp временем получения. |
| Несинхронные стаканы | Один повтор получения обоих стаканов; при повторном отказе сохраняются оба времени, возраста, разница и пороги. |
| DEX_VIRTUAL_ENTRY_STALE | Добавлены конкретные возраста входной/обратной DEX-цены и CEX-стакана. Старая цена не становится новой. |
| DEX_SCAN_TIMEOUT | Добавлена task-local запись этапа: DEX BUY/SELL, очередь/HTTP безопасности или CEX-стакан. При отмене снимок сохраняется до очистки контекста. |
| SIMULATION_FAILED | Сохраняется scope token/pool/counterasset. Неуспешная симуляция не становится подтверждением безопасности или общим verdict токена. |
| HONEYPOT_DETECTED | Ответ сервиса по конкретному пулу остаётся блокировкой маршрута. Ошибка описания исправлена: это не утверждение, что WBNB/USDT во всех пулах опасны. |
| RISK_HIGH | Тот же принцип scope; не заменять31 на допустимое значение20. Проверяется и withToken при наличии в ответе. |
| TAX_HTTP404 | Неизвестный результат для запрошенного пула. Cache/backoff остаются; не использовать ответ другого пула как доказательство. |
| TAX_UNAVAILABLE | Timeout сохраняет provider, сеть, контракты и пул. Рынок не исполняется при отсутствии доказательств. |
| Ненулевой налог | Сохраняются сторона, пул, counterasset, фактические bps; ничего не обнуляется. Исправлен скрывавшийся числовой счётчик экспорта без ослабления редактирования секретов. |
| Идентичность/ERA | Сохраняются ожидаемые и полученные контракты/сети. Разные активы не объединяются по тикеру. Нужна подтверждённая идентичность, а не выключенный gate. |
| ETH/WETH | Реализована отдельная PAPER-конверсия для канонического Ethereum WETH↔nativeETH: сеть1, ETH metadata без токен-контракта, явные WRAP/UNWRAP,30000 дополнительных gas units как непроверенное PAPER-допущение. Не распространяется на другие wrappers/сети. |
| Пустые сети F/ENSO/ENJ/EDGE | Остаётся диагностируемая нехватка биржевых данных; никакой выдуманной сети. Metadata кеш ограничен60с, после срока данные запрашиваются снова. |
| Недоступный ввод/вывод | Теперь сохраняются конкретные required_operations, их true/false/null, active и источник CURRENCY/NETWORK. false и unknown не смешиваются в фактах. |
| Нет API MEXC | Пользователь отложил подключение. Публичная цена не заменяет сетевые данные; запрет сохранён. |
| Сети не поддерживаются | Длинный cooldown300с для обеих причин. Не изображать адаптер сети работающим, пока нет проверенной поддержки котировок/безопасности. |
| Размер/residual | Исправлено предложение уменьшения по фактическому превышению CEX cap. Подбор residual использует середину допустимого остатка, максимум4 новых проверки. Остаток≤$0.05, шаги и ceiling не ослаблены. Если подбор не завершён, сохраняются попытки и пороги. |
| Reverse NET / partial NET / spread / stress | Отказы с отрицательной экономикой остаются. Числа не исправляются ради входа. Для CEX SPREAD_BELOW_MINIMUM теперь сам отказ содержит observed/threshold; остальные CEX причины сохраняют план и профиль. |
| Нет DEX inventory/borrow | Обратный арбитраж остаётся недоступным: нельзя заменить отсутствующую ногу одиночным LONG. |
| Aligned | Остаётся аналитическим сообщением, не входом по исторической цене. |

## Проверка

Новые регрессии: counterasset mismatch, scope pool/global verdict, безопасное
редактирование счётчиков/секретов, категории HTTP400 без свободного текста,
повтор stale book, уменьшение DEX размера под CEX cap, точный статус сети,
оба полных ETH/WETH PAPER-цикла с сохранёнными conversion и расходом газа.
Синтетические тесты не добавляются в рыночную статистику.

Локальная попытка read-only обращения Honeypot.is из среды разработки получила
HTTP403; это не результат Railway и не доказательство ошибки его параметров.
Реальные сервисы могут отказывать после релиза. Не обещается устранение сбоев
сторонней инфраструктуры навсегда, доступность ликвидности или прибыль.
Текущие настройки пользователя, комиссии, balances и история сохраняются.
LIVE, реальные orders/withdrawals/wallet writes по-прежнему запрещены.
